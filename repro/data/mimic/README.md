# MIMIC-IV CKD->ESRD audit data

This directory holds inputs and intermediate artefacts for the real-world
shortcut audit (paper Section 5 + Appendix F.x). Raw MIMIC-IV data is **not**
shipped: PhysioNet credentialing is required.

## Layout

```
data/mimic/
|- raw/                # PLACEHOLDER. Drop the MIMIC-IV `hosp/` CSVs here.
|  +- hosp/
|     |- diagnoses_icd.csv
|     |- admissions.csv
|     +- patients.csv
|- codes/              # Public CCS mapping (HCUP / AHRQ), shipped.
|  |- CCS_DX_mapping.csv
|  +- CCS_DX_categories.csv
|- processed/          # Generated by `python -m src.mimic.build_ckd_cohort_ccs`.
|  |- ckd_cohort_ccs.csv
|  |- ckd_cohort_ccs_stats.txt
|  |- discriminative_codes.csv
|  |- lag_analysis.csv
|  +- descriptive_stats.txt
+- processed/training/ # Generated by `python -m src.mimic.prepare_training_data`.
   |- vocab.json
   |- X_{train,val,test}_{ordered,shuffled}.csv
   +- y_{train,val,test}_{ordered,shuffled}.csv
```

The visit-level robustness experiment additionally produces:

```
processed/training/
|- visit_level_{train,val,test}.pkl
+- visit_level_meta.pkl
```

## How to obtain the raw data

1. Apply for credentialed access at https://physionet.org and complete CITI training.
2. Sign the MIMIC-IV Data Use Agreement.
3. Download MIMIC-IV v3.1 and copy the three files listed above into
   `data/mimic/raw/hosp/`.

The audit only needs `diagnoses_icd.csv`, `admissions.csv`, and `patients.csv`.

## Path overrides

All scripts read paths from `src.common`:

| Variable          | Default                                           |
|-------------------|---------------------------------------------------|
| `MIMIC_DIR`       | `<REPRO_ROOT>/data/mimic`                         |
| `MIMIC_RAW`       | `<MIMIC_DIR>/raw/hosp`                            |
| `MIMIC_PROCESSED` | `<MIMIC_DIR>/processed`                           |
| `MIMIC_TRAINING`  | `<MIMIC_PROCESSED>/training`                      |
| `MIMIC_CODES`     | `<MIMIC_DIR>/codes`                               |
| `MIMIC_RESULTS`   | `<RESULTS_DIR>/mimic`                             |

Override any of them with environment variables to keep raw MIMIC outside the
repo, e.g. `export MIMIC_RAW=/path/to/mimic-iv/hosp`.

## CCS mapping provenance

`codes/CCS_DX_mapping.csv` and `codes/CCS_DX_categories.csv` are derived from
the AHRQ Healthcare Cost and Utilization Project (HCUP) Clinical
Classifications Software (CCS) for ICD-9-CM and ICD-10-CM. They are public.
